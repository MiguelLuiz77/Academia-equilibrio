# Academia Equilíbrio

Landing page responsiva feita com React, Vite e Tailwind CSS.

## Como rodar

1. Instale o Node.js.
2. No terminal, dentro desta pasta, execute `npm install`.
3. Execute `npm run dev` e abra o endereço mostrado no terminal.

Para gerar os arquivos de produção, execute `npm run build`.

## Onde editar

Preços, telefone, endereço, mensagens do WhatsApp, textos, modalidades, métricas, instrutores e fotos da galeria ficam em `src/data/config.js`. Os arquivos de imagem e vídeo ficam em `public/assets/`.
